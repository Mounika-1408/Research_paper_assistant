# 📚 Research Paper Assistant

An AI-powered Research Paper Assistant built using LangChain, ChromaDB, HuggingFace Embeddings, and Groq Llama 3.3.

The assistant allows users to load multiple research papers, ask questions, understand difficult concepts, and receive answers with source citations.

---

## 🚀 Features

- Load multiple research papers
- Semantic search using ChromaDB
- HuggingFace Embeddings
- Retrieval-Augmented Generation (RAG)
- Ask unlimited questions
- Source paper and page number
- Persistent Vector Database
- Modular architecture

---

## 🛠️ Tech Stack

- Python
- LangChain
- ChromaDB
- HuggingFace Embeddings
- Groq API
- Llama 3.3 70B Versatile
